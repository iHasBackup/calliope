# Handoff: Changes since last package (25 Oct 2026)

## Overview
This is a **delta** on top of `design_handoff_crooked_moon/`. It lists only what changed. Everything not mentioned here is unchanged from that package (README.md, REGISTRATION.md, CMS.md, CROSSWORD.md).

Changes:
1. Registration: question 07 copy.
2. Registration: class tile label sizing.
3. Registration: subclass is now required.
4. **New page:** public Calendar at `/calendar`.
5. Content schema: `system` and new `schedule` fields.
6. Admin: Game system field, calendar settings, a submit-based schedule change flow, a History log, and layout fixes.

## About the design files
The files in `reference/` are **HTML design prototypes**. They show intended look and behaviour and are not production code. Recreate them in the existing codebase's framework and conventions. The `.dc.html` files use inline styles and a small template runtime. Read them for values and behaviour; do not port the runtime.

## Fidelity
High-fidelity. The visual system is Modernist: Archivo for all type, zero radius everywhere, 2px rules, single accent. Tokens are unchanged:
- Accent `#ec3013` (`--color-accent`), plus ramp steps `--color-accent-100…900`
- Ground `#f3f2f2` (`--color-bg`), ink `#201e1d` (`--color-text`)
- These pages run inverted: background `--color-text`, text `--color-bg`
- Panel fill: `color-mix(in srgb, var(--color-bg) 7%, var(--color-text))`
- Muted text: `color-mix(in srgb, var(--color-bg) 60–70%, transparent)`
- Hairlines: `color-mix(in srgb, var(--color-bg) 10–14%, transparent)`

## 4. New page: Calendar (`/calendar`)
Public, read-only, no login. It shows every campaign's sessions: past, current and upcoming. Full spec: `reference/CALENDAR.md`. Prototype: `reference/Calendar.dc.html` and `reference/calendar-data.js`.

### Layout (max-width 1440px, page padding `clamp(10px, 4vw, 48px)`)
1. **Sticky top bar** (57px, 2px bottom rule). Left: a 28×28 red square "C" mark and "CHOCOBIE" (Archivo 800, uppercase, 0.08em tracking). Right: link "The Crooked Moon →" (600, 13px, uppercase) to the campaign home page.
2. **H1 "CALENDAR"**: Archivo 800, `clamp(40px, 8vw, 88px)`, line-height 0.9, tracking -0.03em, uppercase. No subheading.
3. **Next session bar**: full width, red fill, min-height 52px, padding `12px clamp(14px,2vw,20px)`, flex-wrap row with a 6px/16px gap. Items in order:
   - Kicker: 11px, weight 500, 0.14em tracking, uppercase. Reads "Next session", "Tonight" or "At the table now".
   - Campaign: 800, 17px, uppercase.
   - "Session 12": 500, 14px.
   - "Wed 28 Oct, 19:00–23:00 GMT+7": 14px.
   - Right-aligned (`margin-left:auto`): a relative label, 500, 14px ("in 3 days", "tomorrow", "in 4 hours", "in 12 min" or "Playing now"), then an arrow.
   - Hover background `--color-accent-600`. Click opens that session's detail. Updates every 30s.
   - There is no countdown block and no campaign list or filter.
4. **Toolbar**:
   - "Today" button: 44px tall, 2px border at 30% ink, 600, 13px, uppercase.
   - Previous and next arrows: 44×44.
   - Period title (H2): 800, `clamp(20px,3vw,28px)`, uppercase, nowrap.
   - View tabs, right-aligned: Week, Month, Agenda, Year. 40px tall inside a 2px border. Active tab is red fill with white text; others are transparent. 600, 13px, uppercase.
   - Below 760px the title takes its own full-width first row.
5. **View body**: top rule is 2px `--color-bg`.

### Views
- **Week** is the default; the last-used view is remembered in `localStorage['chocobie-calendar-view']`. Weeks start on Monday.
  - Grid columns: `56px repeat(7, minmax(0,1fr))`. Header cells show the weekday (11px, **400**, 0.14em) and the day number (Archivo **500**, 22px, 34×34). Today's number sits in a red square with white text.
  - Hour rows are 52px. Hour labels are 11px, weight 400, muted and right-aligned. Hours span the earliest start to the latest end across all campaigns, plus 1h on each side.
  - Events are absolutely positioned. Overlapping events split the column into lanes. Event content: time range (11px, 400), campaign (800, 13px, uppercase), title (12px).
  - Today's column has a 6% accent tint and a 2px red now-line with a 10px red square at its left end.
  - Empty week: "No sessions this week. The table rests."
  - Below 760px: a stacked day list instead of the grid, with "Nothing scheduled" for empty days.
- **Month**: rows of 7 cells.
  - At 1024px and above: cells are 112px tall and show up to 3 chips ("19:00 The Crooked Moon"). Beyond that, "+N more" in `--color-accent-300` opens that week.
  - Below 1024px: cells are 64px tall and show 6px colour bars. Tapping a day lists its sessions under the grid; empty days say "Nothing scheduled."
  - Day numbers are 500, 14px, in a 26×26 box. Days outside the month are at 35% ink.
- **Agenda**: 8 weeks from the cursor, grouped by month. The month header is 800, 13px, `--color-accent-300`, with a 2px rule.
  - Wide rows: `14px 110px 1fr auto` (colour square, time, campaign + title, status tag).
  - Below 760px: `12px 88px 1fr`, with the status tag hidden.
  - Empty: "Nothing on the calendar in this stretch."
- **Year**: 12 mini months, `repeat(auto-fill, minmax(min(100%,160px),1fr))`, with a 16px column gap. Session days fill with the campaign colour, and today gets a 2px ink outline. The month name and "N sessions" link to Month view.
- **Navigation step**: week ±7 days, month ±1, agenda ±28 days, year ±1.

### Event states
- Each campaign has a tone with a background, text and border colour:
  - `accent`: red fill, white text.
  - `ash`: `--color-accent-900` fill, `--color-accent-100` text, `--color-accent-400` border.
  - `stone`: 24% ink mix, ground text.
- **Past**: background is `color-mix(in srgb, <tone bg> 45%, var(--color-text))` and the border is transparent. Opacity is not used, so contrast stays intact.
- **Cancelled**: transparent background, 1px dashed tone border, muted text with strikethrough. The session stays visible and is not numbered.
- Status tags: Played, Playing now, Tonight, Upcoming, Moved, Extra, Cancelled.

### Session detail
- Opens on event click; Esc or a backdrop click closes it. At 760px and above it is a right drawer, `min(440px,100%)` wide, full height, with a 2px red left border. Below 760px it is a bottom sheet, max-height 88vh, with a 2px red top border.
- **Header row**: colour square, campaign name, and a 44×44 close button.
- **Main info**:
  - Kicker: "Session 09", "Extra session · 10" or "Cancelled session", followed by the status tag.
  - Title: Archivo 800, 32px, uppercase.
  - "Wednesday 28 October 2026", then "19:00–23:00 GMT+7 · D&D 5e (2024)". The game system is left out when empty.
  - "Moved from Wed 14 Oct" and the change note, when present.
- **Recap**: shown **only on the most recent played session**, under the heading "Last session recap", with the body and tag chips. If that session has no recap: "No recap posted yet."
- **Party**: heading "Party · 4", then a 2-column grid of tiles with 2px gaps. Each tile has the panel fill, a 32×32 ink-on-ground initial, the name (800, 14px, uppercase, ellipsis) and the class (12px, muted).
- **Open seat**: shown for upcoming sessions when the campaign has open seats. "1 seat open at the table" plus a red "Apply for the seat →" button linking to registration. If registration is closed: "Registration is not open yet."
- **Actions**:
  - "Add this session to my calendar · .ics" (2px ink border).
  - "Add all upcoming sessions · .ics": up to 60 sessions, shown when there is more than one.
  - "Campaign home →".

### Loading skeleton (project rule)
- Shows until campaign data has loaded.
- Ink-tint blocks (`color-mix(in srgb, var(--color-bg) 7%, var(--color-text))`), zero radius.
- Opacity pulse 1 → 0.45 → 1 over 1.4s ease-in-out, infinite. No motion under `prefers-reduced-motion`.
- `aria-busy="true"`, `aria-label="Loading calendar"`.
- A `showSkeleton` preview prop forces it on.

### Session generation (`calendar-data.js`)
- A campaign has: `id, title, system, tone, start, end?, weekday (0=Sun), hour, duration, every (weeks), tz ('GMT+7'), homeUrl, registerUrl, openSeats, party[], recaps[{date,title,body,tags}], changes[]`.
- Sessions repeat every `every` weeks from the first `weekday` on or after `start`, through `end`. Open-ended campaigns generate 400 days ahead. Times are wall-clock in `tz`; convert to UTC for .ics.
- Changes:
  - `cancel`: marks the session cancelled. It stays visible and is not numbered.
  - `move`: sets `toDate` and/or `toHour` and records `movedFrom`.
  - `extra`: adds a session on `date` at `toHour`.
- Recaps attach by date.
- Campaign status comes from the dates relative to today: running, upcoming or finished.
- **The Drowned Bell and Ashen Pilgrims are placeholder campaigns.** Replace them with real data.
- Suggested API: `GET /api/calendar?from=&to=`, which returns campaigns plus server-expanded sessions. `GET /api/calendar/:campaignId.ics` serves a subscribable feed and replaces the client-side download.

## 5. Content schema additions (`campaign-content.js`)
```js
system: 'D&D 5e (2024)',            // campaign-level game system (free text)
schedule: {
  weekday: 3, hour: 19, timezone: 'GMT+7',   // existing
  start: '2026-08-05',              // first session date (YYYY-MM-DD)
  end: '',                          // last session date, optional
  duration: 4,                      // hours, 1–12
  changes: [ { id, type: 'cancel'|'move'|'extra', date, toDate?, toHour?, note? } ],
  history: [ { id, changeId?, undoOf?, at /*ISO*/, kind: 'cancel'|'move'|'extra'|'remove', action, detail, note } ]
}
```
When loading, missing `schedule` keys fall back to the defaults.

## 6. Admin changes (`reference/CampaignAdmin.dc.html`)

### Campaign → new "Game" panel (above Current arc)
- **Game system**: a text input with a datalist of suggestions: D&D 5e (2024), D&D 5e (2014), Pathfinder 2e, Call of Cthulhu 7e, Mörk Borg, Daggerheart. It writes `system` and is saved with the top Save button.

### Schedule
- The section description now reads "Drives the next-session countdown and the calendar."
- **Day / Start time / Timezone grid**: `repeat(3, minmax(0,1fr))` at window widths of 700px and above, a single column below. Inputs align to the bottom.
- **Bug fix**: the Day and Start time selects now show the saved value. Each option gets `selected`; previously they showed "Sunday" and "12:00 AM".
- **"Next session" preview** is two lines: the label (11px, 700, `--color-accent-400`), then the date ("Wed 28 Oct · 7:00 PM GMT+7", Archivo 800, 20px).

### Schedule → new "Calendar" panel
- Intro: "Shown on chocobie.site/calendar. Sessions are generated weekly from the first session date."
- **Fields**:
  - First session (date)
  - Last session, with a muted "optional" (date)
  - Session length, with a muted "hours" (number, 1–12)
- Grid: `minmax(0,1fr) minmax(0,1fr) minmax(120px,160px)` at 700px and above, a single column below. Labels are a fixed 16px tall and nowrap; inputs are 44px. These fields are saved with the top Save button.
- **"Change the schedule"**: three action tiles in `repeat(auto-fit, minmax(min(100%, 300px), 1fr))` with 8px gaps, so they sit three across or one per row, never 2 + 1.
  - Tile: min-height 64px, padding 14px 16px, ink background, 1px border at 18% ground.
  - Tile hover: `--color-accent-400` border and an 8% accent tint.
  - Icon: 22px, `--color-accent-400`, Lucide-style calendar with square caps and joins.
  - Title: Archivo 700, 14px, uppercase, nowrap.
  - Description: 13px, muted.
  - Tile copy:
    - **Cancel a session** (calendar with an X): "Strike one night off. It stays on the calendar, crossed out."
    - **Move a session** (calendar with a right arrow): "Shift one night to another date or start time."
    - **Extra session** (calendar with a plus): "Add a one-off night outside the weekly slot."
- **New flow**: clicking a tile replaces the tiles with **one inline form**, which has a 2px red border and 16px padding.
  - Heading: "Cancel a session", "Move a session" or "Add an extra session".
  - Fields: Session date (labelled "Date" for an extra session); New date (move only); Start time (move and extra, defaulting to the weekly hour); "Note shown on the calendar" (placeholder "e.g. DM is travelling").
  - Buttons: **Submit →** (red, 44px) and Cancel (outline).
  - Validation, shown inline in `--color-accent-400`: "Pick the session date." ("Pick a date." for an extra session) and, for a move, "Pick the new date."
  - **Submit saves immediately**, without the top Save button. It writes the change to `schedule.changes` and a row to `schedule.history`, merges both into the saved snapshot so unrelated unsaved edits stay unsaved, flashes "Saved" and closes the form. Submitted changes are **not** listed in this panel.

### Schedule → new "History" panel (below Calendar)
- Header: "History", with "Submitted changes apply to the calendar right away" on the right.
- Rows are newest first, max 100. Columns: `150px 1fr auto` at 700px and above, `1fr auto` below.
  - Timestamp: "25 Oct 2026, 14:05", muted, tabular numbers.
  - Action tag:
    - Cancelled: ground fill, ink text.
    - Moved: red fill, white text.
    - Extra session: `--color-accent-200` fill, `--color-accent-900` text.
    - Undone: 16% ground fill.
  - Detail: "Session on Wed 4 Nov", "Wed 4 Nov → Thu 5 Nov, 7:00 PM" or "Sat 7 Nov, 7:00 PM".
  - The note, when present.
- **Undo**: a 36px outline button on rows whose change is still active. It removes the change, logs an "Undone" row and saves immediately.
- Empty: "No schedule changes yet."
- Backend: write the history rows server-side in the same transaction as the change.
